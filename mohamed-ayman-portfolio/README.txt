MOHAMED AYMAN — DARK GOLD PORTFOLIO WEBSITE

FILES
- index.html: complete website (HTML + CSS + JavaScript in one file).
- assets/Mohamed_Ayman_CV.pdf: copy of the CV uploaded for this project.
- MASTER_PROMPT.md: reusable prompt for further improvements or AI-assisted edits.

HOW TO VIEW LOCALLY
1. Extract the ZIP file to a folder on your computer.
2. Open the extracted folder.
3. Double-click index.html. It will open in Chrome, Edge, Firefox, or another browser.
4. The website does not need installation, a framework, or a local server for basic viewing.

HOW TO EDIT
- Open index.html in Visual Studio Code (recommended) or Notepad.
- Use Ctrl+F to find the exact text you want to change (name, role, summary, dates, skills, etc.).
- Contact details and the LinkedIn URL appear in the Contact section near the bottom of the file.
- To change the gold palette, edit the CSS variables near the top of the <style> section: --gold, --gold-bright, --gold-deep, and --bg.
- Keep the PDF at assets/Mohamed_Ayman_CV.pdf, or replace it with your updated CV using the same filename so the Download CV button keeps working.
- Add real project images, screenshots, drawings, and links only when they are yours and approved for public sharing. The current project cards are honest text summaries, not invented project files.

IMPORTANT CV DATE CHECK
The uploaded PDF still lists the Pharco role as "January 2025 – Present". The portfolio uses "January 2025 – October 2026" to reflect the later departure date you shared. Before publishing, replace the PDF in the assets folder with an updated CV so the website and downloaded document agree.

HOW TO PUBLISH FREE
Option A — GitHub Pages:
1. Create or sign in to a GitHub account.
2. Create a new public repository, for example: mohamed-ayman-portfolio.
3. Upload index.html and the assets folder (keep the same folder structure).
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. GitHub will provide your public website URL after deployment.

Option B — Netlify:
1. Open https://app.netlify.com/drop in your browser.
2. Drag the extracted website folder (the folder containing index.html and assets) onto the page.
3. Netlify will publish it and give you a public URL.
